# Floors, not exact pins.
#
# This runs on whatever Python the person trying the lab already has, which is
# not a version we get to choose. Exact pins to a September 2024 release meant
# that on Python 3.14 pip could not find a wheel for pydantic-core (a compiled
# Rust extension) or for uvicorn's httptools/uvloop/watchfiles, fell back to
# building them from source, and failed on a machine with no Rust toolchain.
# The error names a compiler, not a version conflict, so it reads as a broken
# machine rather than a stale requirement.
#
# Upper bounds stop at the next major so a future breaking release cannot walk
# in on its own. Reproducibility is the thing being traded away here, and for a
# demo tool run on other people's laptops that is the right way round.
fastapi>=0.115,<1
uvicorn[standard]>=0.30,<1
boto3>=1.35,<2
pyyaml>=6.0.2,<7
pydantic>=2.9,<3
